## 核心能力

### meta-builder 能做什么？

**输入（5 种任务类型）**：
- "做个作品集网站"（新项目）
- "给我的网站加个博客功能"（迭代）
- "每次写 API 文档都很麻烦"（skill 化）
- "把 Redux 改成 Zustand"（重构）
- "有个想法，不确定怎么开始"（只是想法）

**输出（自动选择执行路径）**：
- 诊断任务类型 + 评估材料完整度 + 识别阻塞性缺口
- 选择最佳执行路径（9 条路径变体）
- 链式调用对应 skill 完成任务

**特色**：
- 🧠 **智能诊断**：三优先级判断（目录状态 > 关键词 > LLM）
- 🔀 **灵活路由**：配置驱动，易扩展
- 🔗 **Skill 链**：管道式调用，幂等执行
- 🛡️ **四重过滤**：只问改变结果的问题
- 🔄 **递归重诊断**：能处理极度模糊输入

## 架构概览

### 三层架构

```
用户输入
    ↓
┌─────────────────────────────────────┐
│ Layer 1：诊断层（Diagnosis）          │
│ ─────────────────────────────────── │
│ • 判断任务类型（5 种）                  │
│ • 评估材料完整度（3 维度）               │
│ • 识别阻塞性缺口（四重判断）              │
│ → 输出：任务卡（Task Card JSON）       │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ Layer 2：路由层（Routing）            │
│ ─────────────────────────────────── │
│ • 12 条路由规则（配置驱动）              │
│ • 决策树（6 节点 + 5 路径）             │
│ • 条件分支（缺口补齐/冲突纠错/降级）       │
│ → 输出：执行计划（Execution Plan JSON） │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ Layer 3：执行层（Execution）          │
│ ─────────────────────────────────── │
│ • 按 skill 序列逐个调用                │
│ • 管道式传参（文件路径 / JSON / 上下文）  │
│ • 每步汇报 + 错误处理                  │
│ → 输出：最终交付物 + 验证结果           │
└─────────────────────────────────────┘
```

## 技术亮点

### 1. 阻塞性缺口的四重判断

**目标**：只问改变结果的问题，避免过度提问

```
每个候选问题必须通过全部 4 个判断：

1. 答案是否已在上下文？
   → 是 → 直接提取，不提问

2. 能否从规格安全推出？
   → 是 → 给候选判断，不提问

3. 不同答案是否会改变（交付物 / 路径 / 验收）？
   → 否 → 取消提问

4. 此刻提问能否带来新决策信息？
   → 否 → 取消提问
   → 是 → 保留问题
```

### 2. 路径 E 的递归重诊断

**能力**：处理极度模糊输入

```
用户："有个想法，不确定怎么开始"
    ↓
诊断 → 任务类型 = 只是想法
    ↓
路径 E → 调用 dbs-jtbd 澄清
    ↓
输出："当用户想管理学习笔记时，需要笔记工具，以便快速记录和回顾"
    ↓
重新诊断 → 任务类型 = 新项目，材料完整度 = 中等
    ↓
补齐缺口 → 材料完整度 = 丰富
    ↓
路径 A-Interactive → 执行 first-flight 链
```

### 3. 配置驱动路由

**易维护**：新增任务类型或路径只需修改配置

```javascript
const ROUTING_RULES = [
  {
    id: 'R1',
    condition: (taskCard) => taskCard.任务类型 === '新项目' && taskCard.推荐模式 === 'Interactive',
    path: 'A-Interactive',
    reason: '新项目 + 交互模式 → 逐步引导'
  },
  // ... 12 条规则
];
```
