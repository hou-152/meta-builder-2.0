## 二、自我改造机制

### 2.1 触发条件

**明确触发**（用户直接说）：
```
"meta-builder 需要改进"
"meta-builder 这个判断不对，应该是 XXX"
"能不能给 meta-builder 加个 XXX 功能"
"meta-builder 的路由规则有问题"
```

**隐式触发**（从对话中识别）：
```
用户："给我的网站加博客"
meta-builder 判断为：新项目
用户："不对，是给现有网站加"

→ 诊断为：用户在纠正 meta-builder 的判断
→ 记录反馈："迭代 vs 新项目判断有误"
→ 询问："要不要改进 meta-builder 的判断逻辑？"
```

### 2.2 自我改造流程

```
┌─────────────────┐
│ 用户反馈输入    │
└────────┬────────┘
         ↓
┌─────────────────┐
│ 识别反馈类型    │ ← 判断：改进自己 vs 其他任务
└────────┬────────┘
         ↓
┌─────────────────┐
│ 读取当前版本    │ ← SKILL.md + references/diagnosis.md + routing.md
└────────┬────────┘
         ↓
┌─────────────────┐
│ 调用 dbs-jtbd   │ ← 分析反馈中的任务："当用户遇到 XXX 时，meta-builder 需要 YYY"
└────────┬────────┘
         ↓
┌─────────────────┐
│ 设计改进方案    │ ← 修改 diagnosis.md / routing.md / SKILL.md
└────────┬────────┘
         ↓
┌─────────────────┐
│ 生成新版本      │ ← 调用 dbs-skill-maker，生成新版 meta-builder
└────────┬────────┘
         ↓
┌─────────────────┐
│ 对比新旧版本    │ ← 列出改动清单（增/删/改）
└────────┬────────┘
         ↓
┌─────────────────┐
│ 询问用户确认    │ ← "这些改动看起来对吗？"
└────────┬────────┘
         ↓
     ┌───┴───┐
     ↓       ↓
   [是]    [否]
     ↓       ↓
备份旧版本  放弃改动
     ↓
安装新版本
     ↓
更新 CHANGELOG
     ↓
汇报完成
```

### 2.3 识别「改进自己」任务

**在 diagnosis.md 中新增判断逻辑**：

```javascript
// Step 0: 检测是否是「改进 meta-builder 自己」任务
function isSelfImprovement(userInput, context) {
  // 检测 1：用户明确说"meta-builder"
  const mentionsSelf = /meta-builder|建站元技能|这个 skill/i.test(userInput);
  
  // 检测 2：用户在纠正判断
  const isCorrection = context.lastDiagnosis && 
                       /不对|不是|错了|应该是/i.test(userInput);
  
  // 检测 3：用户提改进建议
  const isSuggestion = /需要改进|有问题|可以优化|能不能加/i.test(userInput);
  
  if (mentionsSelf || (isCorrection && isSuggestion)) {
    return {
      type: 'self-improvement',
      subtype: mentionsSelf ? 'explicit' : 'implicit',
      feedback: extractFeedback(userInput, context)
    };
  }
  
  return null;
}

// 如果是自我改进任务，跳转到 PATH_SELF_IMPROVE
if (isSelfImprovement(userInput, context)) {
  return {
    任务类型: '自我改进',
    用户意图: '改进 meta-builder 自身能力',
    材料完整度: '丰富',
    阻塞性缺口: [],
    推荐模式: 'Interactive'
  };
}
```

### 3.2 版本号规则

**语义化版本**：`v{major}.{minor}.{patch}`

- **major**（主版本号）：不兼容的架构变更
  - 例：从三层架构改为四层架构
  - 例：删除某个执行路径
  
- **minor**（次版本号）：向后兼容的功能新增
  - 例：新增执行路径
  - 例：新增任务类型
  
- **patch**（修订号）：向后兼容的问题修复
  - 例：修复判断逻辑错误
  - 例：优化路由规则

**当前版本**：`v1.0`（阶段 0-3 完成）

## 四、版本升级流程

### 4.1 升级脚本（upgrade.sh）

```bash
#!/bin/bash
# meta-builder 版本升级脚本

set -e

NEW_VERSION=$1
OLD_VERSION=$(cat ~/.agents/skills/meta-builder/.current-version)

if [ -z "$NEW_VERSION" ]; then
  echo "错误：未指定新版本号"
  echo "用法：./upgrade.sh v1.1"
  exit 1
fi

echo "准备从 $OLD_VERSION 升级到 $NEW_VERSION"

# 1. 检查新版本是否存在
if [ ! -d "~/.agents/skills/meta-builder/versions/$NEW_VERSION" ]; then
  echo "错误：版本 $NEW_VERSION 不存在"
  exit 1
fi

# 2. 备份当前版本（如果还未备份）
if [ ! -d "~/.agents/skills/meta-builder/versions/$OLD_VERSION" ]; then
  echo "备份当前版本 $OLD_VERSION"
  mkdir -p ~/.agents/skills/meta-builder/versions/$OLD_VERSION
  cp ~/.agents/skills/meta-builder/SKILL.md ~/.agents/skills/meta-builder/versions/$OLD_VERSION/
  cp -r ~/.agents/skills/meta-builder/references ~/.agents/skills/meta-builder/versions/$OLD_VERSION/
fi

# 3. 切换软链接到新版本
echo "切换到新版本 $NEW_VERSION"
rm ~/.agents/skills/meta-builder/SKILL.md
rm ~/.agents/skills/meta-builder/references
ln -s versions/$NEW_VERSION/SKILL.md ~/.agents/skills/meta-builder/SKILL.md
ln -s versions/$NEW_VERSION/references ~/.agents/skills/meta-builder/references

# 4. 更新 .current-version
echo "$NEW_VERSION" > ~/.agents/skills/meta-builder/.current-version

# 5. 显示变更内容
echo ""
echo "升级完成！"
echo "当前版本：$NEW_VERSION"
echo ""
echo "变更内容："
cat ~/.agents/skills/meta-builder/versions/$NEW_VERSION/metadata.json | jq '.changes'

echo ""
echo "如需回滚，运行：./rollback.sh $OLD_VERSION"
```

## 十、风险与限制

### 风险

1. **软链接在不同系统的兼容性**
   - Windows 可能不支持符号链接
   - 缓解：提供复制模式作为备选

2. **版本冲突**
   - 用户手动修改文件后升级可能冲突
   - 缓解：升级前检测是否有未提交修改

3. **自我改进可能引入错误**
   - 自动生成的新版本可能有 bug
   - 缓解：强制人工审查 + 回滚机制

### 限制

1. **需要 skill 可被识别**
   - 目前 meta-builder 仍无法在会话中被调用
   - 自我改进机制暂时无法实际运行

2. **依赖外部 skill**
   - PATH_SELF_IMPROVE 依赖 dbs-jtbd, dbs-skill-maker
   - 如果这些 skill 不存在，自我改进无法工作
