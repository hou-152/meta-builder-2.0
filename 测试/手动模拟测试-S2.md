## 发现的问题

### 问题 1：PATH_B 缺少 wayfinder

**位置**：routing.md 的 PATH_B 定义

**期望行为**：
迭代项目应该先调用 `wayfinder` 梳理现有项目脉络，再生成新版 PRD

**实际行为**：
直接跳到 `first-flight-prd`

**错误类型**：B 类（判断过程错误 - 路径选择）

**修复优先级**：P0（核心功能，必须立即修复）

**修复方案**：
在 routing.md 的 PATH_B 定义中，skill 序列第一个位置加上 wayfinder：
```javascript
PATH_B: {
  condition: (card) => card.任务类型 === "迭代" && card.阻塞性缺口.length === 0,
  skills: [
    { name: "wayfinder", purpose: "梳理项目脉络" },  // 新增
    { name: "first-flight-prd", mode: "iteration" },
    { name: "first-flight-phases" }
  ]
}
```
