**isLocalRefactor 判断**：
```javascript
function isLocalRefactor(card) {
  const userInput = card.原始输入;
  
  // 关键词
  const localKeywords = ['这个', '这段', '单个', '局部', '某个'];
  if (localKeywords.some(kw => userInput.includes(kw))) {
    return true;
  }
  
  // 提到具体文件或组件
  if (/\.tsx?|\.jsx?|\.vue/.test(userInput)) {
    return true;
  }
  
  return false;
}
```

**判断过程**：
- userInput = "把整个项目的状态管理从 Redux 改成 Zustand"
- 局部关键词检查：❌（包含"整个项目"，不是局部关键词）
- 具体文件检查：❌（未提及具体文件）
- 结果：`isLocalRefactor = false`

**结论**：全局重构
