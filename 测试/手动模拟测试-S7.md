## 发现的问题

### 问题 1：PATH_A_BATCH 输出路径不明确

**位置**：routing.md 的 PATH_A_BATCH 定义

**期望行为**（根据样本集）：
- BRIEF.md 放在项目根目录
- 其他文档放在 `iterations/v1-initial/` 下
- 所有文档带 TODO 标注

**实际行为**（routing.md）：
- 只说"输出 6 份文档"
- 未明确文件路径结构

**错误类型**：C 类（对外表达不清晰 - 输出路径）

**修复优先级**：P1（影响使用体验，需要明确）

**修复方案**：
在 routing.md 的 PATH_A_BATCH 定义中，明确输出路径：
```javascript
PATH_A_BATCH: {
  condition: (card) => card.任务类型 === "新项目" && card.推荐模式 === "Batch",
  skills: [
    {
      name: "first-flight",
      mode: "batch",
      output: {
        "BRIEF.md": "项目根目录",
        "iterations/v1-initial/PRD.md": "首版需求",
        "iterations/v1-initial/DESIGN.md": "首版设计",
        "iterations/v1-initial/ARCHITECTURE.md": "首版架构",
        "iterations/v1-initial/CONTENT.md": "首版内容",
        "iterations/v1-initial/AGENTS.md": "首版 AI 入口"
      },
      note: "所有文档带 TODO 标注"
    }
  ]
}
```
