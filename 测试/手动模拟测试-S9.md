### 判断局部 vs 全局重构

根据 routing.md 的 isLocalRefactor 函数：

```javascript
function isLocalRefactor(card) {
  const userInput = card.原始输入;
  
  // 关键词
  const localKeywords = ['这个', '这段', '单个', '局部', '某个'];
  if (localKeywords.some(kw => userInput.includes(kw))) {
    return true;
  }
  
  // 提到具体文件或组件
  if (/\.tsx?|\.jsx?|\.vue/.test(userInput)) {
    return true;
  }
  
  return false;
}
```

- userInput = "把这个 UserProfile 组件拆成更小的组件"
- 局部关键词检查：✅（包含"这个"）
- 具体文件检查：不需要（已经通过关键词判断）
- 结果：`isLocalRefactor = true`

**结论**：局部重构
